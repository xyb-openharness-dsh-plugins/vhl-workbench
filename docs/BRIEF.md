# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：Von Hippel-Lindau 综合征患者及家属；覆盖确诊后的多器官年度筛查登记、影像与生化报告归档、家系筛查信息记录和就诊资料准备。家属代记需标明记录者，家系成员检测线索只记录医生原话，不判定遗传风险。

场景：眼底、内耳、脑与脊髓、腹部影像和儿茶酚胺等生化结果散在不同年份、不同医院与不同载体中，年度筛查项目多且漏检不易发现。工作台按器官与日期整理自述与资料，帮助回看记录、核对来源并准备想问医生的问题，不代替医生判断。

核心流程：
1. 打开工作台，查看最近记录、本年度已做与未做的筛查条目和想带去复诊的问题
2. 记录一次筛查结果、一次随访感受或归档一份影像/生化报告，写清日期、器官、记录者、原文、单位和来源，缺失项保留为空
3. 按器官与日期并列回看本人/家属感受、各器官筛查结果与医生原话，不推导因果或判定
4. 导出就诊准备材料，回去能看到同一份已确认记录

完成结果：患者或家属能把一次筛查或报告核对入库，并在复诊前导出带来源和待问事项的材料；年度筛查矩阵按记录自动回显已做/未做，不生成诊断或随访计划建议。

初始布局选择：business-first
