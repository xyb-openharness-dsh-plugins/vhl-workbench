## 问题、用户与最小闭环

患者拿到的是散在不同年份、不同医院、不同科室的结果（眼底、内耳听力、脑与脊髓影像、腹部影像、儿茶酚胺生化），年度筛查项目多，漏检不易发现，复诊时难以按器官与日期还原经过。

- 服务主体：VHL 综合征患者本人与家属照护者（家属代记需标记录录者）。
- 输入：自述症状/感受、筛查结果、影像与生化报告、医生原话答复。
- 动作：记录/归档 → 核对（来源、日期、器官）→ 按器官与日期并列回看 → 导出就诊材料。
- 输出：带来源与「待问医生」清单的就诊准备材料；年度筛查矩阵按记录自动回显已做/未做。
- 失败恢复：AI 候选拒收零副作用；更正=新增版本不删除。
- 成功标准：患者能把一次筛查或报告核对入库，复诊前导出完整材料。

## 方案与 ADR

选「器官分区档案 + 年度筛查矩阵 + 跨器官时间线」方案：
- 备选A：纯按时间线组织（家族通用底本）——不满足 VHL「哪个器官查过没有」的查漏诉求。
- 备选B：按器官建独立档案树——导航过深，跨器官事件还原不了。
- 选择：器官分区为报告档案主组织，时间线做跨器官事实串联，筛查矩阵做查漏视图。三者读同一事实层。

只做：事实记录、来源核对、材料整理。阈值与求助短语未过临床审核一律【待核】占位。
