## 差异化条目（场景 → 功能 → 怎么验）
1. 场景：每年该做哪些器官筛查、上次各是什么时候、有没有漏项 → 功能：年度筛查矩阵（器官 × 检查项目 × 年份状态，未找到记录的显式列出「未找到记录」）→ 验收：矩阵条目与筛查项目清单逐项对账；切 A/B 档案不串档；无催促判定词。
2. 场景：多器官病灶（CNS 血管母细胞瘤、肾细胞癌、胰腺病灶、肾上腺病灶、内淋巴囊肿瘤等）结果散在各科报告 → 功能：按受累器官组织的报告档案分区 + 跨器官统一时间线 → 验收：器官导航、时间线、报告页三处对账一致，孤儿页 = 0。
3. 场景：常染色体显性遗传，亲属检测问题 → 功能：家系信息线（只列医生原话 + 已做/未做检测事实 + 就诊问题清单）→ 验收：全站 grep 无遗传概率/必须检测类判定文案。
4. 场景：复查散在眼底科、耳科、神经外科、泌尿外科、内分泌科 → 功能：就诊准备导出（按器官归组 + 待问清单）→ 验收：导出材料含来源与记录者，私密条目过滤，回去能重读同一份记录。
5. 场景：病程以「筛查事件」而非「疗程」推进 → 功能：时间线事件类型＝检查/就诊/症状/缓解开始/加重（非肿瘤 1.3 节口径）→ 验收：无疗程编号、无 day_index、无阶段标签语义。

## 与基准仓的刻意不抄
- breast-cancer：不抄肿瘤分期、治疗线序、疗效应答、肿瘤标志物口径。
- aml：不抄血液肿瘤治疗阶段语义、预后与危险度分层；只抄导航分组、生活影响线、事件泳道结构。
