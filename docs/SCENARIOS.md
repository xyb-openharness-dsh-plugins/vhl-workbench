# SCENARIOS · vhl-workbench

0 访谈推演场景（每场景：入口 → 步骤 → 可观察产物 → 回首页）。

## SC-01 刚确诊登记（档案A）
入口：看板「记录」按钮。步骤：选器官 → 填检查项/日期/结果原文/来源 → 核对入库。产物：报告档案出现该条 + 筛查矩阵该格变为已做。回首页：看板最近记录 +1。

## SC-02 年度查漏（档案B）
入口：筛查计划页。步骤：按年份切到本年度 → 看各器官状态 → 未找到记录的条目进待问清单。产物：待问清单条目出现。回首页：待问数徽标更新。

## SC-03 报告归档（档案B）
入口：报告档案页。步骤：选器官 → 归档报告（名称/日期/机构/原文/私密标记）。产物：报告表新增一行 + 时间线事件出现。回首页：最近报告表可见。

## SC-04 症状记录与代记（档案A）
入口：时间线页「记录感受」。步骤：填日期/内容/记录者（本人/家属）→ 可标私密。产物：时间线事件出现并标记录录者。回首页：时间线最近事件 +1。

## SC-05 就诊准备导出（档案B）
入口：就诊准备页。步骤：勾选要带的内容 → 生成导出（私密自动排除）→ 保存。产物：导出文件生成，内容与已确认记录一致。回首页：返回后状态一致。

## SC-06 AI 候选核对（档案A）
入口：任一记录页「和 AI 讨论」。步骤：候选生成（演示态）→ 逐项核对 → 拒收。产物：拒收后状态不变（零副作用）。回首页：无新增。

## SC-07 家系信息（档案B）
入口：家系信息页。步骤：登记亲属检测事实（已做/未做/医生原话）。产物：家系清单条目出现。回首页：返回。
