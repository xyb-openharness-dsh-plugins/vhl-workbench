## 场景主流程（一期）

S1 刚确诊：建档案 → 首次筛查结果登记 → 看板呈现已做/未找到记录 → 导出首次就诊材料。
S2 长期随访：年度筛查逐项登记 → 时间线还原年度经过 → 矩阵查漏 → 多科室复诊前导出。
S3 代记：家属记录症状与陪同就诊 → 记录者标注 → 私密条目三出口过滤。

## 患者视角红线核对

医生任务冒充患者需求排查：本仓无"医生工作流"功能线；每条功能线服务于患者信息整理与就诊准备。F6 家系线服务于患者被问到的家族问题准备，不做遗传咨询判定。
