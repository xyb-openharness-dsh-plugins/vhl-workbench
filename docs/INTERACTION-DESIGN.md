# INTERACTION-DESIGN · vhl-workbench（IP1 · 2026-11-08 · v0.1 草案）

基准声明：结构基准＝小粉宝 breast-cancer-workbench/prototypes/v0.4（hero、五 Tab、分类眉题、最近报告表）+ 小橙宝 aml-workbench/prototypes/v0.2 #mind/mind-burden（导航分组、生活影响线、事件泳道）。只抄结构与元素体系，不抄病种语义。

## 一级导航（患者信息维度，非医生任务）
1. 看板（最近记录 / 筛查回显 / 待问数 / 最近报告表）
2. 筛查计划（年度筛查矩阵：器官 × 项目 × 年份状态）
3. 报告档案（按受累器官分区的眉题区块 + 最近报告表）
4. 时间线（跨器官事件泳道：检查 / 就诊 / 症状 / 缓解开始 / 加重）
5. 指标趋势（可比组标注的历年对比，不做好坏判定）
6. 就诊准备（问题清单 + 导出）
7. 家系信息（事实记录 + 医生原话）
8. 设置（全局设置页，按 SETTINGS-DESIGN）

## 交互路径（一期 7 条 = SCENARIOS SC-01..07）
每个 (view,sub) 至少被一条路径经过（IP2 穷举以脚本计数为准）；入口名=导航 key=界面文案逐字一致（IP3）；每条路径有可观察产物 + 一步回首页（IP4）。

## 编辑与 AI
- 每页显式编辑入口 ≤1，手工入口收进「⋯ 更多」（IP6）。
- 每个可写实体有 AI 候选通道（标"—"的红线实体除外）；候选逐项核对、拒收零副作用（IP5）。
- 每页标题行常驻「和 AI 讨论」，携带本页关键信息（无判定词）进输入框，不代发（IP11）。
- 顶栏 AI 走 vhl:agent-draft 协议（Q15）。
