# DEV-REQUIREMENTS · vhl-workbench

## 一、红线（不可让步）
1. 不做诊断与处置建议；不写"建议治疗/可能复发/可以停药/无需就医/治愈率/风险分级"。
2. 患者数据本机优先，不引入静默上传；私密三出口（看板/导出/AI）代码级同一过滤函数。
3. 医学内容标注来源与版本；未核实项写「未核实」或【待核】；不用相邻疾病外推。
4. 不复制指南临床内容，只引用病种名称与版本号作为范围参照。
5. 医生任务冒充患者需求 → 独立评审一票否决。
6. 无判读列（diagnosis / risk_level / activity_score 类派生判定不入库）；派生值读时算。

## 二、病种语义红线（非肿瘤家族）
- 表达用「受累器官 / 筛查节律 / 已做未做」，禁用病期、线序、预后、生存期、疗效应答、肿瘤标志物口径。
- 筛查矩阵只回显事实（已做/未做/记录缺失），不生成"应该做"的催促判定；未做项文案为「未找到记录」+「可带去复诊问医生」。
- 家系线只记录医生原话与已做/未做检测事实，无遗传概率计算。

## 三、家族基线（1.1 节全量适用）
令牌先于组件；正文 15px 行高 1.65；三段外壳（原型声明条→侧栏→顶栏+页脚）；按钮 42–44px；统一类名 .card/.pill/.notice/.empty/.table-wrap/.section-title；私密三出口同过滤；AI 输出永远「候选/预览」；断点 1180/900/600；折叠用原生 details；空状态必给下一步按钮。

## 四、验收分级
一切结果四态：通过（带数字/file:line）/ 失败 / 跳过（原因）/ 待人工（缺什么证据）。禁"大体完成"。
